봉사활동 참여 정보를 다양한 정렬, 필터링 기능과 위치정보, 기관에 대한 정성적인 평가와 함께 제공하여 봉사활동 참여에 대한 접근성을 높이고자 기획하게 된 프로젝트입니다.
