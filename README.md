# Team20_Android

20조 안드로이드.

## 프로젝트 소개
봉사활동 참여 정보를 다양한 정렬, 필터링 기능과 위치정보, 기관에 대한 정성적인 평가와 함께 제공하여 봉사활동 참여에 대한 접근성을 높이고자 기획하게 된 프로젝트입니다.

## 참여 인원
본인 포함 안드로이드 3명, 백엔드 2명

## 본인 역할
홈, 상세 페이지 개발.

## 개발 기간
24년 9월~11월

## 본인 사용 기술
안드로이드 스튜디오, 코틀린, 리사이클러뷰, 데이터바인딩, 힐트, 레트로핏, 카카오 맵 API, 라이브데이터 등

## 주요 기능
- 카카오 로그인
- 카카오 지도
- 봉사활동 평가
- 보기 좋은 봉사활동 정보

- 카카오 소셜 로그인을 이용한 회원관리
